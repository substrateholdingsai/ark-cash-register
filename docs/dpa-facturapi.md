# Acuerdo de Tratamiento de Datos (DPA) — Facturapi

**Controlador:** Substrate Holdings LLC (Ark Systems).
**Encargado:** Facturapi (facturapi.io).
**Objeto:** Timbrado y cancelación de CFDI 4.0.

## 1. Datos tratados
- Datos fiscales del emisor/receptor: RFC, razón social, régimen, CP.
- Datos de la factura: conceptos, montos, impuestos, uso CFDI.
- Datos de contacto (email) para envío de CFDI.

## 2. Finalidades
- Timbrar CFDI ante el SAT.
- Cancelar CFDI.
- Generar PDF/XML.

## 3. Obligaciones del encargado
- Usar datos solo para timbrado/cancelación.
- Conservar CFDI por 5 años (obligación fiscal).
- Medidas de seguridad (TLS, API key).
- Notificación de brechas.

## 4. Vigencia
Indefinida mientras exista la relación comercial.
