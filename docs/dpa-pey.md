# Acuerdo de Tratamiento de Datos (DPA) — Pey

**Controlador:** Substrate Holdings LLC (Ark Systems).
**Encargado:** Pey (api.pey.mx).
**Objeto:** Procesamiento de cobros CoDi y verificación de cuentas bancarias.

## 1. Datos tratados
- Datos de comercio: alias, nombre, CLABE, RFC, entidad.
- Datos de pagos: monto, concepto, estado, transaction_id.
- Datos técnicos mínimos para operación de la API.

## 2. Finalidades
- Generar cobros CoDi (QR/Push/Link) y confirmar pagos vía webhook.
- Registrar cuenta bancaria ante Banxico.
- Auditoría y conciliación.

## 3. Obligaciones del encargado
- Usar datos solo para las finalidades acordadas.
- Aplicar medidas de seguridad (TLS, HMAC en webhooks).
- Notificar brechas sin demora indebida.
- Permitir auditoría razonable.
- Eliminar o devolver datos al terminar el servicio (sujeto a retención legal).

## 4. Transferencias internacionales
- Pey opera en México; datos no salen del territorio salvo infraestructura de Cloudflare (ver DPA Cloudflare).

## 5. Vigencia
Indefinida mientras exista la relación comercial.
